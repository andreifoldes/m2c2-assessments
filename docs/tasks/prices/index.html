Prices

An associative memory task with a learning and a recognition phase. Participants are shown item–price pairs and asked to remember them, then tested on which price was paired with each item. Prices are localized to the participant's currency.

  • Duration: ~120 s
  • Source: ARC · Nicosia et al., 2022 — custom implementation
  • Launch URL: https://andreifoldes.github.io/m2c2-assessments/assessments/prices/

Example URL commands​

# Plain launch (debug mode: results shown on-screen)
https://andreifoldes.github.io/m2c2-assessments/assessments/prices/

# Suppress the completion screen
https://andreifoldes.github.io/m2c2-assessments/assessments/prices/?show_end_screen=false

# With camera recording
https://andreifoldes.github.io/m2c2-assessments/assessments/prices/?webcam=1

# With eye tracking
https://andreifoldes.github.io/m2c2-assessments/assessments/prices/?webgazer=1

# Customized assessment parameters (values shown are the defaults)
https://andreifoldes.github.io/m2c2-assessments/assessments/prices/?number_of_items=10&learning_duration_ms=3000&show_good_price_question=true

# Production: submit results to your server
https://andreifoldes.github.io/m2c2-assessments/assessments/prices/?token=<TOKEN>&callback_url=<CALLBACK_URL>

Session parameters​

Handled by the launch wrapper (results submission and optional sensors), not by the assessment itself.

ParameterTypeDefaultDescription
callback_urlstring—URL to POST results to when the assessment ends.
embedstring—Set to 1 for embedded mode (e.g. an ESMira PWA iframe): on completion, results are posted to the parent window via postMessage instead of an HTTP callback.
lightstring—Set to 1 or true to enable ambient light sensing (where the browser supports the AmbientLightSensor API). Participants see a consent prompt; lux readings are recorded during the task and exported at session end.
show_end_screenstringtrueSet to false or 0 to suppress the green "Assessment Complete" screen after results are submitted. A Telegram WebView closes immediately instead of showing the confirmation.
tokenstring—Authentication token for results submission. When absent (along with callback_url), the assessment runs in debug mode and displays results on-screen instead of submitting them.
tutorialstringtrueSet to false or 0 to skip the tutorial screens (alias for the show_tutorial assessment parameter).
webcamstring—Set to 1 or true to enable optional camera recording. Participants see a consent prompt; if they accept, the front camera records and the video is saved locally to their device at session end.
webgazerstring—Set to 1 or true to enable browser-based eye tracking via WebGazer.js. Participants see a consent prompt, then a 5-point gaze calibration. Gaze coordinates are recorded throughout the task and exported as a CSV file at session end. Can be combined with webcam=1.

Assessment parameters​

Parameters marked URL can be set as URL query parameters; the rest are fixed deployment defaults.

ParameterTypeDefaultURLDescription
number_of_itemsnumber10✅Number of item-price pairs per session
learning_duration_msnumber3000✅Display duration per item in learning phase (ms)
show_good_price_questionbooleantrue✅Show 'Is this a good price?' question during learning phase
show_tutorialbooleantrue✅Show the tutorial before the test
min_price_distance_usdnumber3✅Minimum separation between correct price and distractor, expressed in USD. Automatically converted to the local currency equivalent using approximate exchange rates.
localestringen-GB✅BCP 47 locale tag (e.g. 'en-GB', 'fr-FR'). Set to 'auto' to detect from the browser.
currencystringGBP✅ISO 4217 currency code (e.g. 'GBP', 'EUR'). Set to 'auto' to infer from locale.
excluded_itemsstring""✅Comma-separated item names to exclude from this session. Use for within-day no-repeat rule (Rule 7).
used_item_pricesstring{}✅JSON object mapping item names to arrays of previously used prices. E.g. '{"Almonds":[3.27,5.82],"Cereal":[7.63]}'. Prevents re-presenting the same item-price pair (Rule 8).
show_trials_complete_scenebooleanfalse (site override; package default true)—After the final trial, should a completion scene be shown? Otherwise, the game will immediately end.
