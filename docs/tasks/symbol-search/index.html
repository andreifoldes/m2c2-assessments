Symbol Search

A processing speed task from the m2c2kit library. Participants see a set of symbol pairs at the top of the screen and must quickly identify which of two bottom pairs matches one of the top pairs.

  • Duration: ~60 s
  • Source: m2c2kit
  • Deployed version: assessment-symbol-search@0.8.33
  • Launch URL: https://andreifoldes.github.io/m2c2-assessments/dist/assessments/@m2c2kit/assessment-symbol-search@0.8.33/

# Plain launch (debug mode: results shown on-screen)

Session parameters​

Handled by the launch wrapper (results submission and optional sensors), not by the assessment itself.

ParameterTypeDefaultDescription
callback_urlstring—URL to POST results to when the assessment ends.
tokenstring—Authentication token for results submission. When absent (along with callback_url), the assessment runs in debug mode and displays results on-screen instead of submitting them.
webcamstring—Set to 1 or true to enable optional camera recording. Participants see a consent prompt; if they accept, the front camera records and the video is saved locally to their device at session end.
webgazerstring—Set to 1 or true to enable browser-based eye tracking via WebGazer.js. Participants see a consent prompt, then a 5-point gaze calibration. Gaze coordinates are recorded throughout the task and exported as a CSV file at session end. Can be combined with webcam=1.

Assessment parameters​

Every parameter below can be set directly as a URL query parameter — the launch wrapper forwards all query parameters to the assessment.

ParameterTypeDefaultURLDescription
number_of_top_pairsinteger3✅Number of pairs to be shown on top. (1-4) Allowed values: 1, 2, 3, 4.
lure_percentnumber0.5✅Percentage of lure trials. Number from 0 to 1. A lure trial is when the incorrect symbol pair on the bottom contains exactly one symbol that is found on the top.(1 unique symbol). A non-lure trial is when the incorrect symbol pair contains exactly zero symbols that match the top. (2 unique symbols.)
lure_position_on_cardstringeither✅If a lure trial, must the lure symbol occupy the top position on the the card, the bottom, or either? If either, then the lure symbol will be equally distributed across trials to be in the top and bottom positions. Allowed values: "top", "bottom", "either".
left_correct_percentnumber0.5✅Percentage of trials where the left pair is the correct answer. Number from 0 to 1.
countdown_duration_msnumber3000✅Duration of the countdown phase, milliseconds. Multiples of 1000 recommended.
after_countdown_transition_duration_msnumber500✅Duration, in milliseconds, of the slide in animation after the countdown phase.
number_of_trialsinteger12 (site override; package default 20)✅How many trials to run.
interstimulus_animationbooleantrue✅Should new trials slide in from right to left?
interstimulus_interval_duration_msnumber500✅If interstimulus_animation == true, the duration, in milliseconds, of the slide in animation after each trial. Otherwise, the duration, in milliseconds, to wait after a trial has been completed until a new trial appears.
instruction_typestringlong✅Type of instructions to show, 'short' or 'long'. Allowed values: "short", "long".
instructionsobject or nullnull✅When non-null, an InstructionsOptions object that will completely override the built-in instructions.
show_trials_complete_scenebooleanfalse (site override; package default true)✅After the final trial, should a completion scene be shown? Otherwise, the game will immediately end.
show_quit_buttonbooleanfalse✅Should the activity quit button be shown?
show_fpsbooleanfalse✅Should the FPS be shown?
show_locale_pickerbooleanfalse✅Should the icon that allows the participant to switch the locale be shown?
scoringbooleanfalse✅Should scoring data be generated? Default is false.
scoring_filter_response_time_duration_msarray[100,10000]✅When scoring, values of response_time_duration_ms less than the lower bound or greater than the upper bound are discarded. This array contains two numbers, the lower and upper bounds.
seedstring or nullnull✅Optional seed for the seeded pseudo-random number generator. When null, the default Math.random() is used.
